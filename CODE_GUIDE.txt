ICSK STATIONERY - CODE GUIDE

FILES
index.html: page structure, six product cards, filters and hidden cart dialog.
style.css: shared ivory/burgundy design, product grid and mobile layouts.
shop.js: quantities, totals, coupons, dialog, filtering and feedback messages.
: six locally saved retailer product photographs.
school-logo.png: supplied school logo.
IMAGE_SOURCES.txt: exact product and image source URLs.

CODE BOUNDARIES
The original record book supplies basic HTML, variables, arithmetic,
conditions and loops. The working cart uses the beginner JavaScript additions
previously approved. The reference-style redesign also requires additional
HTML and a small shared CSS stylesheet. It is NOT strictly record-book-only.
There are no frameworks, packages, build steps, external fonts or server calls.
Readable code is preferred to compressed/minified code.

COMMENT SYNTAX
HTML: <!-- # explanation -->
CSS: /* # explanation */
JavaScript: // # explanation
Comments explain each HTML line, JS statement and CSS rule group without
appearing on the storefront. A bare # would not work as a comment.

BASIC FLOW
Add button -> addItem(product index) -> change quantities -> renderCart().
Prices are whole fils: 450 + 850 = 1300, displayed as KD 1.300.
A 10% discount is rounded to the nearest fils. Coupon codes never stack.
SAVE250 is inactive below 3000 fils and reactivates above that threshold.
The cart is not stored permanently: refreshing resets it.

JAVASCRIPT CONCEPTS
Arrays keep product names, prices and quantities at matching positions.
Functions group actions; parameters identify the product being changed.
getElementById finds one page element. textContent safely changes its text.
innerHTML renders fixed product data into cart rows or a summary.
Coupon/search text is never inserted as HTML.
value reads a field. trim and toUpperCase/toLowerCase normalise user text.
Math.round rounds to whole fils; toFixed(3) formats dinars.
querySelectorAll finds cards or filter buttons; dataset reads data attributes.
includes tests search matches; hidden controls whether a card is displayed.
aria-pressed marks the selected category for styling and accessibility.
setTimeout hides a feedback message after 3.5 seconds; clearTimeout cancels
an older timer so fast clicks do not hide a newer message too soon.

CART DIALOG
The native dialog element is hidden initially. Only the Bag button calls
openCart(), which calls showModal(). This makes the background inactive and
keeps keyboard focus in the panel. close() or Escape closes it. This is a
visibility control, not a password or security lock.

CSS CONCEPTS
Selectors target shared classes. Grid places product cards in columns; flex
aligns navigation and controls. Gap, padding and margins create spacing.
Border-radius rounds cards and buttons. object-fit: contain shows the whole
product photo. mix-blend-mode: multiply blends white image backgrounds with
the warm page. Positioning arranges the hero photographs and side dialog.
Media queries adjust layouts on phones/tablets. clamp scales heading sizes.
The ::backdrop selector dims the page behind the open cart.
Focus outlines and meaningful button names support keyboard use.

EDITING PRODUCTS
Update both the visible product card in index.html and the matching arrays
in shop.js when changing names or prices. Keep array positions aligned.
The data-search attribute must also reflect a changed name or brand.
Prices in JavaScript are fils, not dinars. Image filenames use product-0.jpg
through product-5.jpg in the same order as the arrays.

ORDER SUMMARY
The summary is a local calculation, not a completed order or payment.
The bag remains intact. Any later cart or coupon change clears the summary.
No customer details, account, inventory system or payment provider is used.
Coupons are locally defined examples, not promotions from the image retailer.

DESIGN REFERENCE

rounded controls, spacious sections and straightforward shopping interactions.
