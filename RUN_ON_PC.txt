ICSK STATIONERY - RUN ON A WINDOWS PC

1. Right-click ICSK_Stationery_Project.zip and select Extract All.
2. Open the extracted folder, then double-click index.html.
3. If asked, choose Chrome, Edge or Firefox.
No installation, server or sign-in is required. The site and product photos
work offline. External product-detail links need an internet connection.

Keep index.html, style.css, shop.js, school-logo.png and the six product image files
in their original positions. Missing photos usually mean the product image files
was not extracted. Missing styling means style.css was moved or renamed.

USING THE SHOP
Browse the collection or use the category filters and search box together.
Add to bag adds one pack without opening the cart.
Click Bag in the top navigation to see the cart. Close with X or Escape.
Use +, minus, Remove or Empty bag to change quantities (maximum 99 packs).
SCHOOL10 gives 10% off. SAVE250 gives 250 fils off subtotals of KD 3.000+.
Only one coupon is applied. Codes ignore outer spaces and letter case.
Create order summary produces an itemised summary without clearing the bag.
Changing the cart or coupon clears an older summary to prevent stale totals.
No real payment is taken and no order is submitted.
Refreshing or closing the page resets the bag and summary.

EDITING
Open the HTML, CSS or JS files in Notepad. Save with Ctrl+S and refresh the
browser. Enable File name extensions in Explorer to avoid saving .html.txt.
Read CODE_GUIDE.txt for the structure and explanation of additional techniques.
